# Smith Ski Guide

Русскоязычный гид по шлемам Smith, маске 4D MAG и линзам ChromaPop. Включает карту магазинов в Варшаве, калькулятор в PLN и сохранение цветовой темы.

## Локальный запуск

Откройте `index.html` или выполните `python3 -m http.server 8000` из каталога сайта. Для подложки карты требуется подключение к OpenStreetMap.

## Публикация

GitHub Pages публикует содержимое корня ветки `main` при каждом обновлении. Сайт не требует сборки.

## Данные и фотографии

Карточки магазинов и материалы Smith связаны с соответствующими разделами сайта. При обновлении предложения синхронизируйте цену в карточке и калькуляторе. Цены в вычислениях хранятся в грошах. Фотографии — Smith Optics. Лицензия Leaflet доступна в `assets/Leaflet-LICENSE`.
