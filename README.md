# Smith Ski Guide

Русскоязычный гид по шлемам Smith, маске 4D MAG и линзам ChromaPop. Включает карту магазинов в Варшаве, калькулятор в PLN и сохранение цветовой темы.

## Локальный запуск

Откройте `index.html` или выполните `python3 -m http.server 8000` из каталога сайта. Для подложки карты требуется подключение к OpenStreetMap.

## Публикация

GitHub Pages публикует содержимое корня ветки `main` при каждом обновлении. Сайт не требует сборки.

## Данные и фотографии

Карточки магазинов и материалы Smith связаны с соответствующими разделами сайта. Предложения и цены отдельных линз хранятся в guide-data.js и shop-inventory.js (в грошах). В shop-inventory.js указаны вариации шлемов WhiteSport и MCK Sport, которые можно было заказать онлайн, и варианты обычной 4D MAG у MCK Sport. Список предложений отсортирован по цене в каждой группе. Калькулятор использует ту же базу и исключает предложения с непроверенной ценой или наличием. Фотографии — Smith Optics. Лицензия Leaflet доступна в `assets/Leaflet-LICENSE`.
